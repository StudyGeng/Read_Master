# Contributing to Read_Master

Thank you for your interest in improving Read_Master. Contributions that fix bugs, improve accessibility, refine the interface, or add useful library features are welcome.

## Getting Started

1. Fork this repository.
2. Clone your fork.

3. Create a new branch:

   ```bash
   git checkout -b feature/your-feature-name
   ```

4. Start the local development multi-server:

   ```bash
   npm start
   ```
