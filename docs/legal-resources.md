# Legal Free Resource Checklist

This is a practical checklist for Read_Master. It is not legal advice, but it helps keep the library focused on resources that are meant to be shared.

## Allowed Resource Types

- Public domain books.
- Creative Commons or other open-license books.
- Open educational resources.
- School-owned resources that your school allows you to publish.
- Author-approved resources where you have written permission.

Do not upload copied paid textbooks, scanned physical books, random PDFs from file-sharing sites, or books where the source does not clearly allow sharing.

## Good Places To Find Resources

- Project Gutenberg: public-domain books, mainly checked under United States copyright rules. Use the book landing page as the source link.
- OpenStax: free textbooks with Creative Commons license terms. Check each book page for the exact license.
- Open Textbook Library: open textbooks that are free to use and distribute with attribution.
- OER Commons: open educational resources with visible usage rights.
- MDN Web Docs: free web documentation with open content licensing. Check attribution and license notes before reuse.
- W3C WAI: free web accessibility learning resources. Link to official pages and check page terms before copying content.

## Admin Checklist Before Saving A Book

- Use the official source page, not a copied file from another site.
- Choose the correct license/source type in the admin form.
- Fill in the source name, such as `Project Gutenberg`, `OpenStax`, or the author/school name.
- Add the official resource URL or upload only a file you are allowed to share.
- Keep attribution information in the book description when needed.
- Tick the legal checkbox only after checking the source, license, and usage rights.

## Attribution Reminder

For Creative Commons resources, record the title, author, source URL, and license type when available. Public domain resources should still keep a source credit so users can verify where the text came from.
